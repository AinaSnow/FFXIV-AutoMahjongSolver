## 默认行为与迁移

- 保留 Off / Hints / Auto-play 和已有自动操作设置。配置 schema 3 从 v2 保留用户字段。
- `EnhancedStrategy=false`、`EnhancedShadowOnly=true`、`SearchBudgetMs=50`。增强策略选择只在显式开启后生效；影子模式记录比较而不替换动作。
- 快照 schema 6 增加独立自风、局号、比赛长度、手局/版本和完整性。旧样本仅可沿已有迁移/兼容读入；缺失字段保持未知，不启用终局加成。权重 schema 3 不静默套用旧权重。
- 未匹配已验证游戏版本时，网络推理停用，继续 UI 读取与内置策略；设置中的 Mortal 开关保持用户原值，状态区显示实际降级原因。
- 归档 schema 4、游戏日志 schema 5 兼容读取旧 ndjson；动作派发与状态变化/超时/外部输入分别统计，UI 结算标注为推断。新建托管归档默认保留 30 天、总量 1 GiB，设置页可改。仅清理含结束标记的直接子目录；活动归档、旧无标记归档和符号链接不清理，刚结束的一份归档保留，因此单份超限时可以暂时超过总量。
- 磁盘/队列失败或损坏行标记不完整。进程卸载不等待落盘；宿主被强制结束时不能保证最后一批记录保存。最后得分为最后观测值，同分时名次未知，不冒充已确认结算。
- `summary.json` 本地统计决策来源、平均/P95 耗时、操作失败、超时兜底、Mortal 状态和损坏行。`shadow` 记录稳定/增强选择差异。没有远程上传。

## 后续验收入口

先按 [协议与 Mortal 说明](mortal.md) 收集当前客户端受控对局，验证解码字段与自杠回执；再扩充完整连续回放。按 [评测说明](evaluation.md) 产生独立训练样本和消融结果，冻结策略/模型/参数后运行 1,000 个验收种子组。平均名次差须 ≤ -0.03 且 95% 区间上界 < 0，四位率差上界 ≤ +0.01，同时无新增非法动作、恢复或重复派发回归，才能考虑更改默认策略。
