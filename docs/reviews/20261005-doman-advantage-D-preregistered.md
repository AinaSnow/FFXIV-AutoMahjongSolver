# 候选D：收益加权动作学习预登记（2026-10-05）

登记于D训练和新开发对照之前。本轮仅检验动作学习目标，沿用既有引擎及Mortal推理，不处理决策之外的工程bug或边界。

## 假设及固定设计

C的价值模型校准改善未转化为策略开发胜出。D检验收益加权动作学习能否比收益分值回归更好地改变动作选择；已有初始梯度诊断不足以将主要问题归因于CQL过强。本实验不声称已确定失败原因。

1. 复用R1的407条完整去重轨迹、128个训练种子106000–106127、141863条可见决策、冻结主体特征，以及C的按种子四折交叉拟合逐手收益。最终效用仍为[1,1,0,-0.25]。不重新拟合价值模型、不产生额外训练牌局。
2. 逐手收益只是动作优势的代理，来自手开始到下一手或终局的价值变化；它包含其他玩家和随机事件的影响，不是同一局面不同动作的反事实优劣。不能依靠该标签单独证明动作正确。
3. 抽样分布仍为R1的每个完整比赛/玩家视角等权。收益温度T固定为该训练抽样分布下的收益标准差，下限0.05；原始权重w=clip(exp(reward/T),0.25,4)，再除以训练抽样分布下的全局均值。均值和标准差全部由训练数据计算，计算公式现在锁定，不接触新开发结果。
4. 从原始基线初始化。训练策略仅用于损失：p(a|s)=softmax(合法动作评分/0.5)。损失为平均w×[-log p(已执行动作)] + 1.0×KL(原始基线策略 || 当前策略)。采用同一个0.5温度计算先验；替代C的收益回归+CQL，不能把结果单独归因于某一个损失项。
5. 主体及BatchNorm完全冻结。公共状态价值行在softmax中抵消，因此D额外冻结它，只更新46个动作优势输出，共47150个参数。保存为原有v4的47行评分头结构，线上推理仍按原有Q的贪心排序执行，不加入随机动作或额外模型。
6. 与C保持同一数据及抽样顺序：seed20261005，1200步、batch512、AdamW学习率1e-5、weight_decay0.01、梯度范数裁剪5；原优化器不恢复。所有动作选择样本包括强制动作都沿用原有分布，不按新结果重采样。
7. 只产出一个最终候选D，不比较中间检查点，不扫温度或KL系数。记录输入文件、训练源码、配置及候选权重哈希；主体、BN和公共价值行逐张量核对不变。

## 对照、预算和停止条件

已检查现有评测manifest，新开发种子1008000–1008099未被使用，与训练106000–106127、价值校准1006000–1006099及先前开发1007000–1007099隔离。

D和既有C分别与原始基线配对，每个100组×4座×双方=800场，共1600物理对局；两轮用同一批新种子，三家对手固定原始基线。按100个种子组计算配对bootstrap区间，派生D减C不另计对局。推理沿用native observation、oracle=false、epsilon=0、AMP=false、quick_eval=true、rule_based_agari_guard=true。

进入后续阶段须同时满足：D减原始基线平均名次<=-0.03、前二率>0、四位率<=+0.01；D减C平均名次<0、前二率>=0、四位率<=+0.01。若不满足，停止该候选，保留产物，不扩量、不解冻主体、不启动自对弈或1000组正式验收，不改线上权重。若通过，先冻结候选，下一阶段另行锁定设计和预算。

本轮上限2 GPU小时；训练最多1800秒；据上一轮实测，两轮开发对照预计约21分钟，含检查和训练预计25–35分钟。不因结果接近门槛临时加种子。
