# 立直动作反馈可行性验证预登记（2026-10-05）

本轮回答现有能力能否在相同可见局面下比较两个动作，以及反馈在固定采样假设下是否稳定。它不是候选E，不训练权重，不扩大完整自对弈数据，也不做执行/UI/协议/兜底工程修复。

## 能力核实与四个局面

Python的OneVsThree只接受整场种子，没有中途分叉接口。Rust的Board可以指定手牌、牌山和得分，Game内部已有完整东风续局逻辑。限定新增一个隔离离线入口：回放无副露、无立直的公开前缀，强制一次动作后继续复用原有Game逻辑，不修改规则或线上库。

从D既有首次立直分歧中，按seed/座位排序，分别取前两个东一至东三局面和前两个东四局面；要求前缀仅有开局、摸牌和舍牌。已选1008000-seat0、1008040-seat1（东一），1008029-seat1、1008098-seat3（东四）。不依据原对局输赢筛选。取D宣告立直后的紧接舍牌作为两个分支共同舍牌，之后结果不用于输入。

比较“此刻立直+共同舍牌”与“此刻不立直+相同舍牌”。不立直分支后续仍由原始Mortal自主决策，可能稍后立直，故不等同于整手强制默听。后续四席均使用原始冻结基线，沿用非oracle、确定性推理与现有和牌辅助。

## 未知牌与限制

输入只保存自家起手/摸牌、公共舍牌/摸切标记、宝牌与比分；对手起手和未公开摸牌全部置为未知。对手非摸切的公开舍牌随机分配到当时13张旧手牌之一的未知槽位，摸切固定相应摸牌槽位，再把剩余实体牌均匀填满其余槽位，包括对手暗牌、后续摸牌、岭上与里宝牌。两动作使用完全相同的一个世界，换世界时同时换对手暗牌及后续牌山，不沿用原牌谱的真实暗牌或未来。

这是未使用对手决策似然的结构性先验，不是已校准的对手手牌后验。即使续打结果在两个采样块里稳定，也只能说明在该先验及固定续打策略下稳定，不能直接作为生产推荐或训练标签。本轮不把先验误差隐藏成采样误差。

已经用每局面128个仅用于结构检查的样本验证了136张牌库存、公开历史可达和隐藏信息清洗；种子从29000000起。这些检查不提供动作收益。

## 固定规模与判据

先做有限运行验证：2个世界的同动作/同动作配对共4条续打，以及四局面各1世界的真分叉共8条；种子从28000000起，全部排除出正式反馈结果。须验证同动作结果完全相同、所有正式世界的根可见观测哈希一致、根动作均合法、可见前缀不变。失败则停止反馈测量，修正限于该离线实验必要实现，不转去工程治理。

正式反馈每局面两块独立的64世界，每世界比较2动作：4×2×64×2=1024条完整至东风终局的续打，统计单位为512个配对世界，不是1024个独立样本。两块世界种子分别30000000和31000000起，各局面偏移1000。不根据中途差值增减规模。

主指标为终局效用[1,1,0,-0.25]的“此刻立直减此刻不立直”配对差；同时报告名次、前二、第四和点数差。每块10000次配对bootstrap，报告99.375%区间（8个局面/块比较的保守多重比较修正，近似描述区间）。只有同一局面的两块差值同向且两个区间均排除0，才标记“该假设下反馈稳定”；否则标为未解决。结果不外推到所有立直决策，不计为线上胜率提升。

模拟上限1 GPU小时，构建上限40分钟；固定规模预计约10–25分钟续打。无自适应扩量、无训练。若结构性先验或反馈不可靠，交付具体限制和结果，不据此继续造一个新权重。
