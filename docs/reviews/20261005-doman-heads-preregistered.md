# 2026-10-05 Mortal 动作评分层 A/B 实验预登记

登记时点：吞吐试跑完成后、正式数据生成及开发对照之前。用户最新范围限定为提升模型决策，不处理自动执行、UI、兜底、协议或其他工程问题。

## 固定设计

- 初始化：当前 v4 基线，SHA-256 `0a88ddad649804d085491b5397d895f596b0e55f30632c549ea145bb44786563`。
- 冻结整个 Brain、参数及全部 BatchNorm 缓冲；仅训练 v4 DQN 最后的 1024 → 47 线性层（价值项及 46 个动作优势）。加载后验证主体逐位相同。
- A 终局效用 `[3, 1, -1, -3]`；B `[1, 1, 0, -0.25]`。按完整比赛最终名次给各决策 Monte Carlo 标签，gamma=1。复用上游 0.5 MSE 收益回归和 CQL 的合法动作 logsumexp 约束，CQL 权重 0.1。
- 这是直接终局收益实验，未声称恢复上游逐手 GRP 收益。现有 GRP 不具备已验证的东风校准，本轮不用它分配奖励；也不增加独立辅助名次头，因为主体冻结时该头的损失不会改变动作评分参数。终局标签仅用于损失，绝不拼入模型输入。
- 相同训练集、相同抽样顺序、独立新 AdamW，学习率 1e-5，weight_decay 0.01，梯度范数上限 5；每候选 1200 步，每步 512 条。只保留最终步作为开发候选，不挑选中间检查点。
- 各完整比赛玩家视角等权抽样，再在该视角内均匀抽决策，避免长局仅因决策较多就占更大训练比重。

## 数据、对手和种子

- 试跑种子 105000–105007，key=42，仅测吞吐，不并入正式训练或验收。
- 正式训练种子 106000–106127，128 组、每组四座，共 512 个物理输出；按完整轨迹去重，四个玩家可见视角用既有 non-oracle Doman GameplayLoader 读取。
- 每批 16 组；对手依次交替当前基线与本机 `mortal_298k.pth`，各 64 个种子组。298k 来源核对沿用 [既有记录](20260925-mortal-dev100.md#候选来源核对)，不是新引入的未审查下载。
- 每场一名基线探索玩家，对另外三名固定对手；epsilon=0.05、温度=0.5、top_p=1。仅模拟探索。所有玩家视角都可贡献其实际动作和终局标签，记录每场对手哈希。
- 东风实验规则沿用已验证的隔离库 `doman-engine-v2-dataset`；原始场风和进度编码不变。runner 内部 quick_eval=true、rule_based_agari_guard=true，模拟与当前 runner 设置相同。AMP 关闭，cuDNN deterministic。
- 不改规则引擎，不修复已知 FF14 规则差异。仅在现有实验规则下解释结果。

## 对照和停止条件

A、B 各使用同一组新开发种子 1006000–1006099、每组候选与基线各四座、每批20组，对手为当前固定基线。每候选800场，合计1600场物理对照；两次基线复跑和相同种子不算新增独立证据。

报告平均名次、前二率、四位率及按种子组的配对 bootstrap 95% 区间（10000次、固定随机种子90731）。训练 loss 不作为棋力提升依据。

开发进入下一阶段的门槛：平均名次差 <= -0.03，前二率差 > 0，四位率差 <= +0.01；若均不满足，本轮停止，不加种子、不加训练步、不改超参数。若两者满足，选择平均名次较低者；完全相同时选 A。

开发通过只允许冻结候选并估算正式验收，不能直接换线上权重。最终验收另行固定1000个未用种子组、8000场配对，平均名次、前二率及四位率仍按主计划门槛判断。

## 吞吐和预算

RTX 5060 Ti，PyTorch 2.10.0+cu128，16GB，2 CPU线程。8组试跑：32场模拟42.63秒，19条去重轨迹、5894条决策，冻结编码8.74秒，总数据阶段52.72秒；模拟约2702场/小时，编码约675决策/秒。编码峰值显存0.49 GiB。

100步训练试跑：A 11.31秒（含首次运算初始化）、B 0.60秒；约4528 / 84895条抽样决策/秒。不能把热启动输出层训练速度解释成完整网络训练速度。

本轮固定计算上限2 GPU小时（含试跑、生成、训练及开发比较），预计约40分钟。数据阶段最多3600秒、每候选训练最多1800秒；正式验收不包含在这一预算内。无云算力购买。

## 复现

固定配置：`tools/evaluation/configs/doman-heads-r1-20261005.json`（本机WSL绝对路径）。入口：`tools/evaluation/finetune_heads.py --config <配置> --output <新目录>`；`--pilot`仅用于试跑。

开发评测复用 `tools/evaluation/compare_models.py`，分别传入候选A/B、`--match-mode doman-quick --groups 100 --offset 6000 --batch-groups 20` 和同一隔离引擎。

原始日志、冻结特征、候选权重和优化器独立存入 `artifacts/finetune/doman-heads-r1-20261005/`；试跑独立在 `doman-heads-pilot-20261005/`。不覆盖线上文件，不以试跑候选代替正式训练。
