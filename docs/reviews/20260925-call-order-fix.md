## 服务端动作核验补充

自动鸣牌/和牌请求另外保留 5 秒的核验窗口，独立于 UI 变化记录。经校验的服务端自身吃、碰、暗杠、明杠、加杠回执与请求种类比对；类型一致记录 `server-confirmed`，例如请求 Ron 却确认 Chi 则记录 `server-action-mismatch`。后一种进入失败总数，并撤销待确认和牌，避免摘要只报告点击 Ok。

这里只验证服务端副露的动作种类，不把窗口消失、结算边界或相同动作种类当作和牌成功、具体吃牌组合和红牌选择的完整验收。未收到可靠回执则保留原来的未确认/超时状态，不编造成功。手动接管、配置切换、离桌取消、新开局/结束及窗口过期都会清除关联；历史重播不发布新的服务端确认。
