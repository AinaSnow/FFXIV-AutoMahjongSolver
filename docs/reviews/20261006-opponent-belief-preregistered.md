# 对手行为与隐牌假设敏感性预登记（2026-10-06）

承接四局面分叉反馈的0/4稳定结果。本轮回答：上一轮结构性隐牌样本在原始对手策略下是否能解释已观察到的舍牌/过牌；增加行为条件后，旧样本是否还具有足够的有效支持。只检查决策反馈，不训练新模型，不处理工程bug、执行链或规则边界。

## 固定输入和预算

沿用`riichi-probe-20261005`的四个局面、两个64世界采样块，共512个世界；用原采样器与原种子重建，不重新筛局面、不新增世界或续打。原先1024条续打结果只在评分完成后用于加权汇总，不参与行为评分或参数选择。输入及脚本哈希在运行前固定。

评分上限20分钟GPU运行时间；预检另限于四个真实世界正对照与一个新世界重复检查，不提供新的动作收益。使用原冻结Mortal、现有隔离库及原生Bot的完整动作转换（包含和牌辅助与快速决策），不改变它们。预算不足或正对照失败则报告未完成，不自动扩量。

## 行为条件

逐个回放根节点之前的对手私人可见历史：起手及摸牌采用该世界的假设；每个对手只看到自己的暗牌及公共事件。自家此前动作视为已知干预，不用自家策略对世界额外加权。

- 舍牌：评估观察到的舍牌，而非事后动作；合法候选中同时包含当时可能的立直/杠/和牌等动作。
- 过牌：他家舍牌后，若该对手存在鸣牌或荣和机会，记录其选择过牌是否符合模型；没有反应机会的强制过牌概率为1。
- 摸切标志：原生Mortal在所选牌与摸牌相同的时候输出摸切。与这个生成约定冲突的世界，在本轮对手模型下权重为0；这不是说真实玩家不能手切同种牌。

先报告与确定性原始Mortal完全相符的世界数及逐动作相符率。真实牌谱的对手暗牌只用于四个正对照，要求所有对手动作相符；禁止把这些暗牌送入正式样本或用来挑选权重参数。

## 固定的四种敏感性设置

原始对手本身是确定性的。为观察偏离原始策略的影响，预先选定两种假设混合概率ε=0.05、0.20。每个非强制决策的观察动作概率设为：

`(1-ε) × I[原生Bot选择等于观察动作] + ε / 合法动作种类数`

它是围绕确定性Bot的假设扰动，**不是由人类数据校准的行为概率，也不是把Q值当概率**。取各事件概率乘积（使用对数计算），分别使用“仅舍牌”和“舍牌+全部可选过牌”两种证据，共四种设置。不根据收益或有效样本数调整ε、截断权重、缩短历史或增加世界。

归一化权重只定义相对于旧结构性采样分布的敏感性分析；旧采样器并未证明给出均匀合法牌山的条件分布，因此不能声称加权后得到真实后验。

## 结果、门槛与解释

每个局面/采样块/设置报告有效样本数`ESS=1/sum(w²)`、最大单世界权重、原始及加权效用差，并对比根节点对手平均向听数。效用保持[1,1,0,-0.25]，差值仍为此刻立直减此刻不立直。

固定支持门槛：每块64世界中ESS至少32，最大单世界权重不超过10%。未通过时只展示描述性差值，不计算容易误导的加权置信区间。通过时才做10000次世界配对重采样，每次重新归一化权重，给出99.84375%近似区间（32项比较的保守修正）。即使区间支持方向，也不是实战棋力或训练标签验收。

如果行为条件让权重集中到极少数世界，下一步应研究在生成时就利用已观察行为的采样方法，并先检查样本支持；不能简单把本轮高权重世界复制成训练集。若支持充分而动作方向对设置敏感，也先定位对手假设。所有设置和失败结果均报告，不从中挑一个有利的结果。
