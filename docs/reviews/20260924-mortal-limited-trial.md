# 2026-09-24 Mortal 有限试用

## 使用方式与边界

不再要求用户随机匹配收集所有特殊牌型。原 dev 输出热重载后，在设置的 Mortal 区域保留 Use Mortal，并手动开启默认关闭的 `Mortal limited trial (2026.09.15 / Emj)`。现有 WSL、模型及自动操作设置保留。开关关闭时恢复原来的完整验证门禁；不会改写用户配置以替用户开启试用。

此开关只准入国际服 `2026.09.15.0000.0000` / `Emj` / 东场的窄范围；EmjL、其他版本、南场等不准入。完整 profile 的 `verified` 仍为 false。不要把试用理解为协议全部验证、规则完全适配或胜率提升。

每局必须重新看到配牌，四家起手分数合计必须为 100000，且牌、座位和本场有效。标准四人桌每人 25000 起分，供托从玩家分数转出，因此总分 100000 用作“开局无留存立直棒”的规则推断。它不是供托字段观测，不能标为已验证计数器；非零供托或不能满足此限定的局全部跳过。当前模型仍有完整半庄与 FF14 短局排名效用等差异，末局取舍仍属实验范围。

开局只保留最近两秒的已登记报文，等实际 UI 变体确认后再按精确版本、opcode、长度和传输来源准入，防止配牌先于窗口出现而丢失。两路消费者各自有界；中途打开没有完整配牌时由内置策略处理，下一局自动重新检查。

任何未支持的杠/补牌、新增宝牌相关事件、未独立确认的 0x113、错误长度、队列丢失、无法发送的输入或不完整历史都会隔离本局，转入内置策略；下一次真实配牌才允许重新接入。网络与 UI 的自身手牌（包括红牌身份）不一致时不提供 Mortal 推荐，沿用已有超时兜底。试用禁用旧的“从 UI 猜补一条网络弃牌”路径。后续未知 opcode 仍不能仅凭未被映射就认定无关。
