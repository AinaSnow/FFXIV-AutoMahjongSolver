# 2026-10-05 Mortal 动作评分层微调：A/B 结果

## 结论

已实际训练并保存两份新决策权重，完成固定的1600场开发对照。**本轮没有达到预登记的继续验收门槛，不替换线上权重，不扩大本轮训练或开发样本。**

B 的前二率点估计高1个百分点，但配对95%区间跨零；平均名次只改善0.01，未达到0.03。A没有改善信号。这不能宣称“模型变强”，也不能证明输出层微调或前二目标在所有配置下都无效。

本轮只做模型训练与决策对照。自动执行链、UI、兜底、游戏协议及其他工程问题均未修改。

## 实际训练

- 512场物理生成输出，完整轨迹去重后407场，141863条玩家可见决策。128个训练种子106000–106127；同种子轮换轨迹与各视角全部留在训练集合。
- 对手为当前基线与已有298k，按16组批次交替，各64个种子组；探索仅用于每场的一名基线玩家，epsilon=0.05、温度0.5。所有玩家各自可见状态及实际终局结果参与训练。
- A效用[3,1,-1,-3]，B效用[1,1,0,-0.25]；直接使用完整比赛终局收益，gamma=1。相同数据、相同随机抽样序列，各1200步×512条，AdamW学习率1e-5，CQL权重0.1。
- 冻结整个Brain及全部BatchNorm统计，仅更新v4 DQN最后线性层的weight和bias（48175个参数）。保存后重新加载，逐项确认主体和归一化缓冲与基线完全相同。
- 独立初始化优化器并保存，不声称恢复原始训练。未使用未经东风校准的GRP；未单独训练不会影响冻结主体/动作头的辅助网络。
- native进度观测，quick_eval和内部rule_based_agari_guard保持true，AMP关闭，沿用现有隔离东风模拟规则，未改规则引擎。

在同一份训练状态上复算合法贪心动作，A有2612/141863次、B有1562/141863次不同于原基线；表明权重确实改变了策略。这只是动作变化诊断，不是独立棋力证据。A/B的训练收益损失下降也不作为提升结论。
