# 候选D：收益加权动作学习结果（2026-10-05）

**D未达到预登记开发门槛，本轮停止，保留原始线上基线。** 开发成绩只用于决定是否继续，不等同于已验证真实FF14上分收益。

## 本轮做了什么

按[预登记](20261005-doman-advantage-D-preregistered.md)，复用R1的407条完整去重轨迹、128个训练种子和141863条可见决策，以及C的交叉拟合逐手收益。D以有界收益权重训练合法动作选择，并用KL约束它偏离原始策略的幅度。它替代了C的分值回归+CQL；本轮不能把成绩差异归因于单个损失项。

只训练动作优势输出的47150个参数，1200步、batch512、AdamW学习率1e-5、weight_decay0.01、梯度裁剪5，抽样顺序与C相同。从原始基线初始化，主体、BatchNorm和公共价值行逐张量完全不变。未挑选中间检查点。

收益温度由训练抽样分布计算为0.24224786。原始指数权重裁剪到[0.25,4]，再全局归一化为均值1，实际范围[0.193666,3.098660]。训练softmax温度0.5，KL权重1.0；推理仍使用原有单个Mortal贪心动作，没有加入训练softmax或随机探索。

逐手收益是动作优势代理，包含其他玩家和随机事件的影响，不能判定同一局面所有未选动作的优劣。训练完成和损失变化均不是棋力证明。
