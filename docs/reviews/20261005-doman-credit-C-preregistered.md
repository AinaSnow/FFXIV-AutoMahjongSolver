# 候选 C：逐手名次价值收益实验预登记

登记于名次模型训练之前；延续用户限定的模型决策范围。模型分歧复盘使用已完成的 B 开发牌谱，不增加实战采样或工程修复。

## 复盘与假设

400份B/基线配对牌谱有236份首次出现玩法分歧，均涉及测试玩家：193次舍牌不同，24次B跳过基线鸣牌，3次B新增鸣牌，16次B未跟随基线立直。首个分歧在东一/二/三/四分别92/57/48/39份，不能把首个分歧频次当成按局归一化动作变化率，因为后续分歧未计数。

首个分歧时与他人同分的100份单独分组；非同分的前二77份，整场净少2次前二、多3次第四；后两名59份净多6次前二、少2次第四。此为同一开发集的描述性子组，存在选择偏差，也不能把整场输赢归因于第一处不同动作。

待检验假设：B把同一终局效用用于所有动作，信用分配过粗；使用局间预期终局效用变化可能改善领先局面的决策。复盘提供研究方向，不证明该原因。

## 固定设计

1. 不重新生成训练牌局，复用R1的407条完整轨迹、128个训练种子、141863条决策和同一冻结主体特征。
2. 名次预测仅使用每手开局时可见的局号、本场、供托和四家分数及其历史前缀。最终名次只作监督标签，预测输入无未来状态。
3. 一次比较两种价值估计：上游GRP的32维单层GRU；四参数Plackett-Luce分数模型，拟合东一到东四的预测尺度。后者是简单名次预测对照，不冒充上游GRU。
4. 固定参考是未拟合分数模型，东一至东四尺度为[2,sqrt(3),sqrt(2),1]（分数单位万）；另报告均匀24种名次排列。两个拟合模型各1000步、batch64；GRU学习率0.001，分数模型0.01。按完整比赛等权抽前缀，不挑中间检查点。
5. 名次校准开发集使用已看过的R1基线种子1006000–1006099，去掉四座重复牌谱，不进入训练。按完整比赛平均NLL、终局效用MSE和前二Brier。选择最终排列NLL较低者；它必须较固定参考降低至少1%，且效用MSE、前二Brier不差，否则停止，不把不可靠价值标签送入策略训练。
6. 若通过，按训练seed模4进行交叉拟合，每份训练牌谱的价值来自没有见过该seed及其任何轮换轨迹的预测模型。四折各用相同固定预算，开发数据只用于上述一次模型家族选择。
7. 对第h手，收益为V(h+1)-V(h)，最后一手用真实终局效用替代下一开局预测；效用仍为B的[1,1,0,-0.25]。各手收益之和须等于终局效用减开局预测，gamma=1。沿用上游逐手收益思路，所有动作仍只能接收当时可见的冻结主体输入。
8. C从原始基线初始化，复用B的相同样本抽样顺序、1200步、batch512、AdamW学习率1e-5、weight_decay0.01、CQL0.1及梯度范数5。Brain及BatchNorm完全冻结。仅变化为交叉拟合的逐手收益标签；不是在B上追加1200步。
9. 只训练一个策略候选C。名次模型仅离线生成收益，游戏推理仍是单个Mortal，不加入多模型投票或外部策略。

## 评测和停止条件

若C产出，C和既有B分别用同一批新开发种子1007000–1007099，各与原始基线配对，四座轮换、每批20组。各800场，共1600物理对照；三家对手固定原始基线，推理与R1设置相同。另从配对结果计算C减B的区间，不与R1旧种子混算。

C继续正式验收的门槛：相对原始基线平均名次差<=-0.03、前二率差>0、四位率差<=+0.01；同时相对B平均名次更低、前二率不低、四位率差<=+0.01。达不到即停止本轮，不改目标、不解冻主体、不扩量。通过才冻结候选，另行估算并登记1000个未使用种子组的正式验收。

本轮总计算上限2 GPU小时；复用数据后预期约25–35分钟，主要为开发对照。既有FF14规则和实战差异保留为结论限制，不在本轮修复。
