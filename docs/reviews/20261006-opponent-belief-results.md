# 对手行为与隐牌假设敏感性结果（2026-10-06）

**四局面的512个旧世界中，0个能完整重现原始对手的全部已观察选择；32组行为加权比较中，0组达到预登记的样本支持门槛。** 本轮没有形成训练标签，也没有提升棋力的验收结论。

本轮是对上一轮动作反馈的补充诊断：沿用四个局面、两块各64世界及已完成的续打结果，检查对手历史行为如何改变这些世界的权重。没有新增续打或模型训练。设计见[预登记](20261006-opponent-belief-preregistered.md)，前一轮见[立直动作反馈结果](20261006-riichi-feedback-results.md)。

## 样本是否解释对手行为

- 四个真实世界正对照的80次对手选择全部重现，重复评分和每位对手的私人信息隔离检查通过。真实暗牌仅用于正对照，不进入正式世界或权重。
- 正式样本的逐次舍牌相符率为1593/8832（18.0%）；有反应机会时的过牌相符率为1304/1490（87.5%）。这是固定假设世界上的描述性比例，不能当作对真实玩家的预测准确率。
- 128/512个世界至少一次与Mortal的摸切输出约定冲突：假设的摸牌等于公开舍牌，但公开标志为手切。按本轮固定对手模型，这些世界权重为0；真实玩家手切同种牌并不违反规则。
- 原始对手是确定性Mortal。额外用ε=0.05、0.20的假设动作扰动观察敏感性，分别纳入仅舍牌、舍牌加可选过牌；ε没有用结果调优，也没有冒充经数据校准的行为概率。

## 结论和下一步

物理合法、公开历史可达，只说明世界可以回放；它没有保证该世界中的对手会作出实际观察到的选择。本轮真实世界正对照通过，但512个正式世界均不能完整重现确定性对手的历史，且32组加权的有效支持全部不足，确认这批结构样本尚不能承担行为条件下的反馈比较。

本轮需要先改善世界的生成分布，不能直接用极少数高权重世界作标签。下一项有限实验应在生成过程中纳入对手历史选择，先用同样四个局面验证行为一致性、手牌多样性与独立重复性；只有这些条件改善，才登记新的成对续打预算。不能将重采样后的重复粒子数量当成独立样本数，也不预设这种方法必然提升棋力。

本轮仍不是校准过的手牌后验：旧结构采样器的条件分布未获校准，ε仅为假设扰动，且只检查了原始Mortal对手及四个特定分歧局面。结果不能直接推广到人类对手，也不能据此唯一解释A/B/C/D为什么未提升。
