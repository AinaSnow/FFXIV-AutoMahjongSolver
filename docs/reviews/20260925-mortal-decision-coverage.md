## 窗口和执行

- 自家摸牌后的通用 Kan 标签由闭手四张同牌、已确认的碰牌和新增一张区分暗杠/加杠；没有可验证候选时保留出牌能力。Discard 与 Kan 并存时不会要求对手弃牌，已排队的模型舍牌可直接采用。
- 吃碰界面优先使用可见子项文字，读取和执行均检查弹窗父节点可见性；延迟调用重新检查全部鸣牌弹窗。
- 已确认对手下一次摸牌、公开/UI 手牌一致、仅有吃碰明杠/跳过且手牌为 13/10/7/... 时，短暂等待界面/网络同步后按 UI 恢复处理。不会产生“模型超时”或重启模型。
- state=15 的过期提示使用本次记录中确实解除残留窗口的取消回调 `[8]`；执行前再次检查当前状态与可见性。和牌、自己回合、未知历史、隔离中的手局均不适用。动作来源为 `ui-recovery`，继续等待结果确认，不能将发送成功视为服务端接受。

## 带供托开局
