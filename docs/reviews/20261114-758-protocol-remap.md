# 7.58 国际服协议 opcode 重映射（2026-11-14）

客户端更新到 `2026.11.03.0000.0000`（7.58）后，原 09.15 配置的 7 个麻将包 opcode 全部失效。本次在一场真实东风战的录包上重新识别 opcode，并新增 `data/protocols/20261103-international-candidate.json`。包长度和解码器都没有改动，只换了 opcode。

## 抓包后端

- Deucalion 1.5.0 在 7.58 上报 `HOOK STATUS: RECV OFF`，收包挂钩失效。
- 升级到官方 1.5.1（dll SHA-256 `4ac5d107…`，与官方 `deucalion.sha256sum` 一致）后恢复正常。
- 官方兼容表只写到 7.57，但实测 1.5.1 可以在 7.58 上收包。
