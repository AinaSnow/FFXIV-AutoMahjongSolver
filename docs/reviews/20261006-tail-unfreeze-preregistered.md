# 有限解冻末段与评分层对照预登记（2026-10-06）

## 路线修正和假设

暂缓继续深化四个旧局面的隐牌诊断。此前512个世界的行为支持不足，只限制该批反事实反馈，不能解释A/B/C/D失败，也不是后续训练必须先解决的前提。本轮直接检验：在相同新数据和同一训练目标下，额外更新最后两个残差块是否比仅更新评分层更有利于东风成绩。

原始模型是54个残差块、256通道的Mortal v4。候选H仅更新46个动作的优势评分行；候选T在H的范围之外，额外更新最后两个残差块（`encoder.net.53`、`.54`）的卷积及通道注意力参数。所有BatchNorm的仿射参数、统计量与计数器都冻结；输入、前52块、末段投影、公共价值行均冻结。不改变比赛观测编码、规则或在线决策逻辑。

两候选均从原始基线初始化，不接着旧候选训练。两者唯一的训练处理差异是上述末段更新（末段使用较小学习率），不从结果中挑层数或学习率。

## 数据和收益

- 新训练种子110000–110255，共256组、1024场物理生成输出，完整轨迹去重后使用四席各自可见决策；同一场和同一牌山只属于训练集合。
- 沿用原采样方法：每场一席原始基线以ε=.05、温度.5探索，四座轮换；训练对手按16组批次交替原始基线和已有298k。298k只是固定训练对手之一，不当作更强教师或待推广候选。
- 收益仍为每手前后预期终局效用[1,1,0,-.25]的差，最后一手衔接实际终局。使用已冻结的C阶段四尺度名次模型，它的训练种子106000–106127与本轮完全隔离；不在本轮重新挑选或校准它。
- 每个完整对局的玩家视角等权抽样。H与T共享数据、收益、指数权重、训练抽样序列和参考策略。收益只是逐手代理，仍有信用分配和动作覆盖限制，不宣称反事实最优动作标签。

## 训练和必要验证

两者各1200步×512条；动作评分层AdamW学习率1e-5，T的残差块学习率1e-6，weight_decay=.01，联合梯度范数裁剪5。沿用D的收益加权合法动作交叉熵及KL(原策略||候选)，策略温度.5、KL系数1。收益指数温度取训练分布标准差、下限.05，原始权重裁剪[.25,4]再归一化。

不更新BatchNorm，不使用AMP，固定2 CPU线程和确定性CUDA配置。只保存最终H/T供开发比较，损失下降和训练动作变化不能用于挑检查点或宣称棋力提升。

冻结前段可预编码为float32中间特征，两个候选共用。先用独立的108000–108003四组数据、每候选20步验证完整推理与切分推理一致、梯度确实到达指定末段、所有其他张量保持逐位相同、保存后动作一致。预检不进入正式训练或开发成绩。

## 独立对局和继续门槛

开发种子1010000–1010199，共200组。H与T各对照原始基线，三家对手均固定原始基线、四座轮换；每个候选1600物理对局，共3200场。两次基线的逐场成绩及玩法哈希必须相同。同组四座相关，按种子组给出10000次配对bootstrap的95%区间，同时计算T−H的直接配对差值。

只用这批开发数据判断是否值得下一阶段：T相对原始基线平均名次差≤−.03、前二率差>0、四位率差≤+.01；同时T相对H平均名次差<0、前二率差≥0、四位率差≤+.01，才认为本轮有限解冻有继续价值。这是开发继续条件，不是已证实棋力提升或上线门槛。若H较好也完整报告，不借此改选一个已验收候选。

若T未满足全部条件，本轮停止，不再扫学习率、层数、种子或检查点；不能由一次失败断言表示能力永远无关。若通过，先冻结权重，再单独登记此前未用的正式验收规模和预算；本轮不替换线上权重。

## 固定预算和产物

本轮总计算上限2 GPU小时：预检5分钟、生成及编码40分钟、两候选训练及必要检查合计20分钟、开发两候选合计50分钟，其余用于收益生成与汇总；阶段记录纳入总额。资源不足、异常数值或越界更新即停止该训练运行，不增加范围。预编码上限500000条决策，不静默截断。估计正式过程约60–80分钟，实际吞吐在预检后记录。

配置`tools/evaluation/configs/doman-tail-r1-20261006.json`；脚本`tools/evaluation/finetune_tail.py`。预检及正式产物分别位于`artifacts/finetune/doman-tail-pilot-20261006/`、`artifacts/finetune/doman-tail-r1-20261006/`。每个候选交付权重、哈希、冻结检查与独立对局结果。严格排除决策之外的工程bug与边界事项。

预检执行记录：第一次预检在生成前因实验脚本未加入既有工具模块搜索路径而终止，没有生成对局或更新参数。补齐该实验入口路径后，原记录保留，改用`doman-tail-pilot-20261006-r2`输出目录重试；种子、数据规模、训练参数和评测设计不变。
