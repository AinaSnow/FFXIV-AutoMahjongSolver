## 数值重复性观察

种子 1001051 的基线四座中，a/b/c 三个牌局一致，d 出现一次近乎平分的选择分歧。第一处差异在事件索引 710（从 0 计数），actor=3：一边选择立直，另一边舍 3s；当时实际推理批大小为 57 与 19。两个相关 Q 值分别约为 0.35022/0.35033 与 0.35021/0.35015，动作排序翻转。这与批大小引起的浮点敏感性相符，但没有宣称已经定位到具体 GPU 算子。
该组名次分布仍为一至四位各一次；得分会不同，所以基线平均牌桌得失分实测为 −7，不能人为强制归零。这里比较的是同组不同座位的执行，尚不能据此认定同一座位重复运行不一致。全部数据保留，另外以同批大小 20 对相关 20 个种子作同模型重复对照。


补充控制使用同样的批大小 20 和种子 1001040–1001059，候选、基线、对手全部设为当前基线权重。160 场正常结束，候选与基线逐座的完整牌局和成绩一致，名次差及其区间均为 0；其中候选侧的 80 场也逐座重现了原实验的 80 场基线牌局。验证结果支持同一运行设置、同一座位的重复性，没有把不同座位间的临界动作差异误当作前后重复失败。

补充控制位于 artifacts/evaluation/models-batch20-control-20260925。本轮总共包含 800 场开发筛选、先行 32 场控制、补充 160 场控制；后两者仅作运行验证，不能合并成更大的独立棋力样本。更换 GPU、精度、引擎或批大小后仍需重新核对，不能保证跨环境逐动作相同。
